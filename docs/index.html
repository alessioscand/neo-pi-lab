03 Beam racing

s16-pi uses beam racing to send each scanline to the TV as soon as it is rendered, in sync with the display's refresh. An emulator with double buffering instead waits for the entire frame to be rendered before presenting it, adding up to one frame of latency.

05 Insert coin

Set-up

  1. Format a micro SD card as FAT32 and copy everything from the zip to its root.
  2. Put your System 16 and 18 games in the s16pi folder as MAME zips. A clone also needs its parent's zip.
  3. Connect a USB pad and the TV, insert the card, switch on.
